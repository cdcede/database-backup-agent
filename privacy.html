Backup Agent — Privacy Policy

Last updated: 2026-10-26

Backup Agent is self-hosted software that runs on the owner's own server. No data is sent to the developer or to any third party.

Google user data

  • The app requests the https://www.googleapis.com/auth/drive.file scope, which only grants access to files the app itself creates.
  • It uses that access solely to upload database backup files to the owner's Google Drive and to delete expired backups it previously uploaded, according to the configured retention period.
  • It does not read, share, sell or transfer any other Google user data.
  • OAuth credentials are stored only in the local configuration file on the owner's server.

Access can be revoked at any time at myaccount.google.com/permissions.
